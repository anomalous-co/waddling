# Claude Code plugin

waddling ships a Claude Code **plugin** that bundles the local MCP server, a set of
`/waddling:*` slash commands, and the [waddling skills](/docs/skills) that teach an
agent to use the tools well. Install it once and your agent is ready to work with
governed lakes.

## Install

```sh
# 1. Add the waddling marketplace
/plugin marketplace add waddling/claude-plugin

# 2. Install the plugin
/plugin install waddling@waddling

# 3. Sign up + link this machine
/waddling:setup

# 4. Connect to a lake
/waddling:connect
```

No API key up front — the plugin starts in onboarding mode and the MCP server saves
your credential on first link (see [Quickstart, Path B](/docs/quickstart#path-b--local-mcp-claude-cli-scripts-other-hosts)).

### Just the MCP server

If you only want the tools (no slash commands or skills):

```sh
claude mcp add waddling npx -- -y @waddling/mcp
```

## What's in the plugin

- **MCP server** — the local `@waddling/mcp` tools (see [MCP tools](/docs/mcp-tools)).
- **Slash commands** — `/waddling:setup`, `/waddling:connect`, `/waddling:status`,
  `/waddling:audit`.
- **Skills** — the [waddling skills](/docs/skills), which activate automatically when
  waddling tools are present and guide the agent through querying, loading, memory,
  and denials.
- **Config** — a `waddling_url` setting (defaults to the hosted control plane; change
  it only when self-hosting).

## Claude Desktop

For Claude Desktop, the same MCP server ships as an `.mcpb` bundle you can install
directly (Settings → Extensions), or configure by hand in
`claude_desktop_config.json`:

```json
{
  "mcpServers": {
    "waddling": {
      "command": "npx",
      "args": ["-y", "@waddling/mcp"],
      "env": { "WADDLING_API_KEY": "sk_agent_…" }
    }
  }
}
```

## Skills, maintained for you

The plugin ships with the official [waddling skills](/docs/skills) — curated by
waddling to keep your agents using the tools correctly as the platform evolves.
They activate automatically whenever the waddling tools are present; there's
nothing to configure. Updates arrive when you update the plugin
(`/plugin marketplace update`).
